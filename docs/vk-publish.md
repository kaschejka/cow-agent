# Публикация в VK: описание, лого, FAQ, соц-инструменты

## Тексты для карточки приложения

**Короткое имя (до 30 символов):**
`Еноты-агенты`

**Краткое описание (подзаголовок, до 80 символов):**
`Карточная дуэль енотов-шпионов: вскрывайте карты, берите ряды, не наберите 66!`

**Полное описание:**

> 🦝 **Еноты-агенты** — быстрая карточная игра по мотивам классики «6 берёт!»,
> но со шпионским настроением и пончиками.
>
> Каждый ход все игроки одновременно выкладывают по карте — меньшие номера
> забирают ряды с штрафными пончиками. Кто первым соберёт 66 🍩 — тот
> «Повелитель Пончиков». Партия живая и хитрая: важно не просто сходить
> сильно, а предугадать соперников.
>
> Что внутри:
> • партии на 2–4 игрока онлайн или против енотов-ботов;
> • партия за 5–10 минут — идеально в очереди или в транспорте;
> • рейтинг place-Elo, зал славы с топами дня и недели;
> • чат с умным антиматом;
> • реванш в один клик;
> • вход в один тап через VK.
>
> Правила осваиваются за минуту — победить сложнее. Удачной охоты, агент!

**Ключевые слова:** карты, еноты, «6 берёт», логическая, семейная, онлайн,
дуэль, быстрый раунд.

## Лого

Файл `assets/logo.svg` — векторная плашка: енот-агент в федоре + значок пончика,
фирменные цвета игры (тёмный фон `#14141f`, золото `#f5b83d`→`#ffd479`).

Требования VK к иконке приложения: квадрат без скруглений (углы режет витрина),
рекомендуемый размер экспорта **1024×1024 PNG**. Конвертация:

```bash
# Inkscape (CLI)
inkscape assets/logo.svg -o logo-1024.png -w 1024 -h 1024
# ImageMagick
magick -background none assets/logo.svg -resize 1024x1024 logo-1024.png
```

Для обложки сообщества/каталога можно использовать тот же файл на подложке
однотонного `#1c1c28`. В самом приложении лого нигде не жёстко задано —
фавикон/иконки добавляются по желанию (`index.html`, `<link rel="icon">`).

## FAQ (для сообщества / обсуждений)

1. **Нужна ли регистрация?**
   Нет. Из VK вы входите автоматически одним тапом. На сайте можно играть
   гостем либо завести аккаунт (логин+почта) — он нужен только для рейтинга.

2. **Как играть с другом?**
   Создатель комнаты нажимает «🌐 Сетевая игра» и выбирает число игроков;
   остальные входят кликом «Войти» из списка открытых комнат. Хосту доступен
   чип «Код: XXXX 📋» — кодом можно продублировать приглашение.

3. **Почему моя последняя карта сыгралась сама?**
   Так задумано: когда в руке остаётся одна карта, она разыгрывается
   автоматически через полсекунды.

4. **Что происходит после того, как все сыграли карту?**
   Несколько секунд («Раздаём карты по рядам…») карты распределяются по столу
   на глазах у всех, затем открывается следующий ход.

5. **Я закрыл игру на своём ходу. Что будет?**
   Через полторы минуты вместо вас играет бот; комната продолжает жить.

6. **Как считается рейтинг?**
   Попарный Эло по занятым местам (старт 1000). Любая сетевая партия между
   живыми людьми идёт в зачёт; гости играют с базовыми 1000, боты на рейтинг
   не влияют.

7. **Кто такой Повелитель Пончиков?**
   Анти-титул игрока, набравшего больше всех штрафных пончиков. В зале славы
   это отдельная номинация — гордиться тоже можно.

8. **Игра зависла / пропал стол?**
   Обновите страницу — вернётесь прямо в текущую партию. Если не помогло —
   проверьте статус: сервер мог перезапуститься вместе с Redis.

9. **Можно ли материться в чате?**
   Можно общаться. Мат заменяется звёздочками автоматически на сервере.

10. **Сколько длится партия?**
    5–10 минут: 3–4 тура по 10 ходов с таймером на 60 секунд.

## Социальные инструменты

### Уже работают в игре

| Инструмент | Где |
|---|---|
| Чат с серверным антиматом | во время сетевой партии |
| Зал славы: топы дня/недели + общий топ-100 | кнопка «🏆 Топы» в меню |
| Рейтинг place-Elo с местами и дельтами | сводки тура/игры, профиль |
| Реванш по обоюдному согласию | финальный экран (2 игрока) |
| Список открытых комнат + код-чип для друзей | меню → «Сетевая игра» |

### Платформа VK (vk-bridge) — что подключается малой кровью

| Метод | Куда добавить кнопку | Эффект |
|---|---|---|
| `VKWebAppShowInviteBox` | главное меню | пригласить друзей из VK |
| `VKWebAppShare` или `VKWebAppShowWallPostBox` | финальный экран | пост о результате (место, ★дельта) |
| `VKWebAppShowStoryBox` | финальный экран | сторис с итогом партии |
| `VKWebAppShowCommunityBox` | меню | подписка на сообщество игры |
| `VKWebAppAddToHomeScreen`? — см. доки bridge | меню | ярлык на домашний экран |
| `VKWebAppStorageSet/Get` | вместо localStorage внутри VK | облачное хранение сессии |

Мост уже подключён (`vkMiniLogin` использует vk-bridge), поэтому вызовы — это
обёртка в 5–10 строк: проверить `window.vkBridge !== undefined` (внутри iframe
VK он есть, на сайте нет) и вызвать метод.

### Сообщество

- Завести группу игры: новости, обсуждение = готовый FAQ (выше), скриншоты залов славы.
- В описании группы закрепить ссылку на приложение.
- Пост-рубрика «Игрок недели» по данным топа — генерируется вручную из вкладки «За неделю».

### Порядок внедрения (рекомендация)

1. Приглашение друзей + подписка на сообщество (меню) — максимум виральности за минимум кода.
2. Поделиться результатом/сторис на финальном экране — эмоциональный триггер.
3. Storage для сессий внутри VK (надёжнее localStorage в iframe).
