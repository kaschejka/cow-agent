# Еноты-агенты — карточная игра

Веб-версия карточной игры **«6 берёт!»** (6 nimmt): игроки одновременно выкладывают карты,
и тот, кто вынужден забирать ряд с «пончиками» (штрафными очками), набирает их как можно меньше.

## Возможности

- **Соло-режим** — партия против ботов прямо в браузере, без регистрации
- **Сетевая игра** — комнаты до 4 игроков, кодовое слово для входа, список открытых комнат
- **Чат в комнате** — со встроенным серверным фильтром мата (антиматом)
- **Авторизация**: гость, логин/пароль, Яндекс и VK OAuth
- Боты подхватывают выбывших игроков, «реванш» после партии, автопропуск хода по таймауту
- Без сборки и зависимостей на клиенте — чистые HTML/CSS/JS

## Требуемое ПО

| Компонент | Версия | Зачем нужен |
|---|---|---|
| PHP | 8.1+ | Backend (`api.php`); расширения: `pdo_mysql`, `redis` (phpredis), `mbstring` |
| MySQL | 5.7+ / 8.0 | Учётные записи пользователей (таблица `users`) |
| Redis | 6.0+ | Сессии, состояние комнат, чат, блокировки |
| Веб-сервер | Apache 2.4+ или nginx 1.20+ | раздача статики и запуск `api.php`; локально достаточно `php -S` |

Клиентская часть не требует Node.js и каких-либо сборщиков.

## Установка

1. Скопируйте файлы проекта в каталог, который будет корнем сайта,
   например `/var/www/cow-test` (Linux) или `C:\www\cow-test` (Windows).
2. Создайте базу данных (таблица `users` создаётся автоматически при первом обращении):

   ```sql
   CREATE DATABASE IF NOT EXISTS cows
     CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

3. Скопируйте `.env.example` в `.env` и укажите свои подключения.
4. Настройте веб-сервер — варианты ниже (Apache или nginx + php-fpm).

Важно: из PHP должен исполняться только `api.php`, а доступ к `.env*` извне
обязательно закрывается — примеры ниже это учитывают.

### Apache 2.4

Виртуальный хост (mod_php; для php-fpm см. комментарий внутри):

```apache
<VirtualHost *:80>
    ServerName cows.local
    DocumentRoot "/var/www/cow-test"

    <Directory "/var/www/cow-test">
        Options -Indexes
        AllowOverride None
        Require all granted
    </Directory>

    # не отдавать .env и другие точечные файлы
    <FilesMatch "^\.">
        Require all denied
    </FilesMatch>

    # если PHP работает через php-fpm (mod_proxy_fcgi), вместо mod_php:
    # <FilesMatch "\.php$">
    #     SetHandler "proxy:unix:/run/php/php8.2-fpm.sock|fcgi://localhost"
    # </FilesMatch>

    ErrorLog ${APACHE_LOG_DIR}/cows_error.log
</VirtualHost>
```

На Windows пути к каталогу и сокету заменяются на диск/путь (`C:/www/cow-test`)
и TCP-адрес пула php-fpm (`fcgi://127.0.0.1:9000`).

### nginx + php-fpm

```nginx
server {
    listen 80;
    server_name cows.local;
    root /var/www/cow-test;
    index index.html;

    # исполняется только api.php
    location = /api.php {
        include fastcgi_params;
        fastcgi_pass unix:/run/php/php8.2-fpm.sock;   # либо 127.0.0.1:9000
        fastcgi_param SCRIPT_FILENAME $document_root/api.php;
        fastcgi_read_timeout 65s;
    }
    location ~ \.php$ { return 404; }

    # скрыть .env* и прочие точечные файлы
    location ~ /\. { deny all; access_log off; log_not_found off; }
}
```

### Локальная разработка без веб-сервера

Нужны запущенные локально MySQL и Redis:

```bash
php -S localhost:8000
```

Откройте http://localhost:8000. Встроенный сервер годится только для разработки.

## Конфигурация (.env)

Все подключения вынесены в файл `.env` в корне проекта.
Приоритет источников: `.env` → переменные окружения ОС → значения по умолчанию в коде.
`.env` добавлен в `.gitignore`, секреты не попадают в репозиторий. Шаблон: `.env.example`.

| Переменная | По умолчанию | Описание |
|---|---|---|
| `DB_HOST` | `127.0.0.1` | Хост MySQL |
| `DB_PORT` | `3306` | Порт MySQL |
| `DB_NAME` | `cows` | Имя базы данных |
| `DB_USER` | `root` | Пользователь MySQL |
| `DB_PASS` | *(пусто)* | Пароль MySQL |
| `REDIS_HOSTS` | `127.0.1.55,127.0.0.1` | Хосты Redis через запятую, берётся первый доступный |
| `REDIS_PORT` | `6379` | Порт Redis |
| `VK_APP_ID` | *(пусто)* | ID приложения VK (пусто = вход через VK отключён) |
| `VK_APP_SECRET` | *(пусто)* | Защищённый ключ приложения VK |
| `AUTH_SESSION_TTL` | `2592000` | Время жизни сессии, сек (30 дней) |

Игровые константы (`HAND_SIZE=10`, `ROW_COUNT=4`, `LOSE_AT=66`, `MAX_PLAYERS=4`,
таймауты хода и пауз) заданы в начале `api.php`.

## Структура проекта

```
├── index.html      единственная страница (SPA)
├── api.php         весь backend: REST API + игровая логика + антимат
├── css/style.css   все стили
├── js/
│   ├── auth.js     формы входа/регистрации, сессия в localStorage
│   ├── game.js     правила, отрисовка стола, соло-режим с ботами
│   └── mp.js       сетевая игра: комнаты, поллинг state, чат
├── .env            конфигурация подключений (не коммитится)
└── .env.example    шаблон конфигурации
```

Состояние комнаты живёт в Redis (ключ `room:<КОД>`, запись под локом `lock:<КОД>`),
чат — список `chat:<КОД>` (последние 100 сообщений). Клиент опрашивает `state`
примерно раз в секунду и применяет обновления по номеру `version` комнаты.

## API

Единая точка: `POST /api.php`, тело — JSON с полем `action`. Ответ — JSON c `ok: true/false`.

### Авторизация

| action | Параметры | Описание |
|---|---|---|
| `register` | `login, password, name?` | регистрация, в ответе `authToken` |
| `login` | `login, password` | вход, `authToken` |
| `logout` | `authToken` | завершение сессии |
| `me` | `authToken` | текущий пользователь |
| `authConfig` | — | отдаёт `vkAppId` (настроен ли VK-вход) |
| `authYandex` | `yaId, name?` | вход через Яндекс |
| `authVk` | `code, redirectUri` | обмен VK OAuth-кода на сессию |

### Комнаты и игра

| action | Параметры | Описание |
|---|---|---|
| `create` | `authToken, max?` | создать комнату, в ответе код комнаты и игровой `token` |
| `rooms` | — | список открытых комнат |
| `join` | `room, authToken` | вход в комнату (только до старта) |
| `state` | `room, token` | полное состояние для игрока (поллинг) |
| `play` | `room, token, card` | выложить карту за ход |
| `choose_row` | `row` | выбрать ряд при конфликте (фаза `choose_row`) |
| `next_round` | — | хост начинает следующий тур после паузы |
| `rematch` | — | хост сбрасывает счёт и собирает всех на новую партию |
| `leave` | — | выход; место занимает бот |

### Чат

| action | Параметры | Описание |
|---|---|---|
| `chat` | `room, token, text` | отправить сообщение (до 200 символов); текст проходит антимат |

## Антимат

Фильтр работает на сервере (`api.php`, функции `filterProfanity*`) — сообщение
сохраняется уже очищенным, клиентские обходы невозможны.

Что умеет:

- нормализация: регистр, ё→е, leet/транслит (`ху@`, `xyu`, `п0издец`), схлопывание повторов букв
- маскировка с сохранением структуры: «б*** проиграл»
- разнесённые по словам буквы («х у й») — сообщение целиком заменяется звёздочками
- защита от ложных срабатываний: «хлебе», «рубля», «мебель», «Уйгурский» проходят

Словари для расширения: константы `PROFANITY_STEMS`, `PROFANITY_JOIN`,
`PROFANITY_LATIN` и правила в `profanityTokenBad()`.

## Разработка и отладка

- Сборка не нужна: правьте файлы и обновляйте страницу (`Ctrl+F5`).
- Быстрая проверка API из консоли:
  ```bash
  curl -d "{\"action\":\"rooms\"}" http://localhost/api.php
  ```
- Логи PHP смотрите в error.log виртуального хоста (Apache) или в журнале php-fpm/nginx.
- Типовые ошибки:
  - «Хранилище недоступно» — Redis не запущен или неверный `REDIS_HOSTS/PORT`;
  - «База данных недоступна» — MySQL не запущен или неверные `DB_*`;
  - пустой экран/старый вид — жёсткое обновление кэша браузера.
